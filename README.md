## 趣旨
中山間地域として位置づけられる埼玉県秩父郡横瀬町は、人口約7,500人ほどの小さな町ながら、都心から約70分でアクセスできる自然豊かな立地を活かし、官民連携で新しい挑戦を次々と受け入れる“チャレンジのフィールド” を提供している自治体です。町が主体となって、企業・大学・個人の実証実験や新規プロジェクトを積極的に受け入れ、「日本一チャレンジする町」 として全国的に注目されています。これらのチャレンジの多くや、町の行政、そして関連団体がリアルな横瀬町を舞台に活動する際に、地図情報はその基盤として必要不可欠なものです。

一方で、一般的に用いられるGoogleマップやゼンリン住宅地図などの商用地図サービスは、営利・非営利問わず多目的で利用可能なオープンデータとして用いることができず、それぞれの利用規約に従った限定的な使い方に制限されてしまう課題もあります。他方、オープンデータとして公開されている地理院地図には多様な地形図及び主題図が地理院タイルとして格納されており、比較的汎用的な地理空間情報の重畳が可能です。しかし、公式の地理院タイルレイヤー以外の組み合わせでは、その利用機能が限定的で、地理空間情報技術に長けていない一般の方々にとっては扱いづらいものがあります。

そこで、本プロジェクトでは、埼玉県秩父郡横瀬町という地域主体を軸に、その地域にとって使いやすい地理空間情報データセットにフィルタすることで、より具体的な活動に貢献できる商用利用も可能なオープンデータのみで構成された汎用地理空間情報データセット構築を目標に、独自のウェブGISポータルを展開します。


## 基本方針
* 収集・再配布するのはすべてオープンデータのみとする
* Webブラウザのみで閲覧・利用できるようにする
* 毎年データの更新を行う（リポジトリは毎年 Fork する）

## 横瀬トイレデータプロジェクト試作版

`toilet-access-map/` に、横瀬町で利用可能なトイレ情報を市民参加で確認・更新・公開していくためのWeb地図試作版を追加しています。

### このプロジェクトについて

本プロジェクトは横瀬町のトイレマップを完成させることが目的ではありません。

市民参加によって地域情報を継続的に整備するための仕組みを設計し、その実証としてトイレ情報を対象にしています。

OpenStreetMapの共同編集性と、CC0による公開データ整備を組み合わせることで、閉鎖的ではない地域オープンデータ基盤を目指します。トイレは最初のケーススタディであり、将来はAED、避難所、ベンチ、給水所、バリアフリー設備などへの展開を想定しています。

現時点では完成済みの網羅的地図ではありません。OpenStreetMap由来の候補19件を `reference` として表示し、そのうちウォーターパーク・シラヤマも未確認の参考地点として扱います。正確な入口位置、設備、トイレ固有の利用時間は未確認です。

GitHub Issueで提供された情報は、GitHub Actionsが形式と座標を検査し、`data/submitted/` の青い確認待ちレイヤーへ自動反映します。これはCC0確認済みデータではありません。独立確認と権利確認を終えた情報だけを `data/verified/` のCC0公開GeoJSONへ移します。OSM参考データは `data/reference/` に分離しており、ルートCC0ライセンスの適用対象外です。

## 現在の位置づけ

本サイトは、ログインなしで確認済みデータを直接編集するシステムではありません。完成済みの公衆トイレ一覧ではなく、情報を継続的に更新するためのWeb地図とデータ整備基盤です。新しいトイレはOSMへ匿名メモを残せ、Issueの受付後は人の転記を待たず確認待ち地図が更新されます。

現時点では、以下の二つの更新経路を提供します。

1. 新しい地点や不足情報をOpenStreetMapへ匿名メモで知らせ、マッパーが確認・共同編集する
2. 独自に確認した情報をGitHub IssueでYOKOZE Atlasへ提供し、Actionsが `submitted` レイヤーへ自動反映する

OSMで編集されたデータはODbLとして共有されます。YOKOZE Atlasの確認待ち情報は自動表示されますが、公開条件を満たしたものだけがCC0データへ昇格します。この二経路により、日常的な更新のボトルネックを減らしながら、ODbLとCC0を分離します。

データは次の三つのレイヤーを分けて表示・管理します。

- **OSM参考レイヤー**: OpenStreetMapから抽出した候補地点です。ODbL 1.0で扱い、位置・設備・利用条件はYOKOZE Atlasとして独立確認していません。YOKOZE AtlasのCC0公開データには含めません。
- **Issue確認待ちレイヤー**: GitHub ActionsがIssueから生成する `submitted` データです。青いピンで自動表示しますが、内容は未確認でCC0公開データには含めません。Issueを閉じると自動的に外れます。
- **YOKOZE Atlas確認済みレイヤー**: 現地調査、施設への問い合わせ、行政・施設管理者からの提供等により独立確認し、権利とCC0公開への同意を確認した情報です。CC0 1.0 Universalで公開します。現在は0件です。

OSMの参考情報をCC0へ自動転記することはありません。OSMを更新する場合はOpenStreetMap上で編集し、YOKOZE Atlasへ情報提供する場合は提供者が自分で確認した内容を別途入力します。
