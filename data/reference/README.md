# OSM参考データのライセンスと帰属

このディレクトリには、横瀬町トイレアクセスマップで参考表示する未確認データを格納します。ルート `LICENSE` の CC0 1.0 Universal は、このディレクトリ内の第三者由来データには適用しません。

## 対象ファイル

- `YOKOZEatlas2026_reference_toilets_v0.1.0.geojson`
- `osm_toilet_candidates.geojson`（OSM由来候補19件の表示用複製）

## データ提供元

- OpenStreetMap
- 横瀬町公式Webページ
- 横瀬町公共施設個別施設計画

## ライセンス

- OpenStreetMap由来の座標と候補情報: ODbL 1.0
- 横瀬町公式Webページおよび公共施設個別施設計画: 公式情報の確認元として参照

## CC0の適用対象外であること

OpenStreetMap由来の座標は ODbL 1.0 の対象です。YOKOZE Atlas 2026 リポジトリ本体の CC0 1.0 Universal データとして扱わず、確認済みCC0データへ直接転用しません。

## 使用目的

- トイレ候補地点の把握
- 公式Web情報との照合
- 問い合わせ、現地調査、管理者確認のための参考表示
