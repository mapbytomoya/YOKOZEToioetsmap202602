# 横瀬町トイレアクセスマップ

このディレクトリは、GitHub Pagesで公開できる静的Web地図の試作版です。ビルド工程、APIキー、サーバーサイド処理は使用しません。

## 現在の状態

- 本サイトは完成済みの網羅的地図ではありません。
- 初期表示では、既存のOSM由来トイレ候補GeoJSONに含まれる全Point Featureを `reference` として表示します。
- ピンの色はWheelmap風に車いす対応状況で分けます。
  - 緑: 利用しやすい
  - 黄: 一部利用可・要確認
  - 赤: 車いす対応なし
  - 灰: 未確認
- 地図設定パネルから車いす対応状況で絞り込めます。
- OSM候補地点はOpenStreetMap由来で、ODbL 1.0の参考情報です。
- 正確なトイレ入口位置、設備、利用条件、トイレ固有の利用時間は独立確認前です。
- 投稿情報は管理者確認後にのみ反映されます。
- 既存ファイルの命名規則は維持し、既存GeoJSON/FGBは変更していません。
- ルートCC0と第三者データのライセンス範囲は異なります。
- 一般利用者向け画面では、ログイン不要の入力方法と4段階の情報提供フローを案内しています。

## 情報提供の考え方

- OSM参考地点のポップアップには「OpenStreetMapで編集する」と「確認した情報を提供する」の二つの経路を表示します。
- OpenStreetMapを編集するにはOSMアカウントが必要で、編集結果はODbLで共有されます。
- YOKOZE Atlasへの情報提供用下書きはブラウザ内で作るため、作成段階ではログインを要求しません。
- YOKOZE Atlasのフォームには、OSM参考情報を読み取り専用で表示します。OSMの名称・種別・座標・設備タグを投稿者の確認情報へ自動転記しません。
- 投稿下書きはGeoJSON、SVG、テキストとして保存・コピーできます。
- GitHub Issueは管理者向けの補助導線で、一般利用者の必須経路にしません。
- 受付先はメール、共有先、Webフォーム、GitHub Issueなどへ後から置き換えられます。
- 確認済みデータは標準的なGeoJSONとして管理し、CC0対象データとOSM参考データを混在させません。

## 二つの更新経路

### OpenStreetMapを更新する

既存のOSM候補地点では、GeoJSONの `@id` が `node/数値`、`way/数値`、`relation/数値` の形式なら、iDエディタでそのオブジェクトを開くURLを生成します。IDがない場合や形式が合わない場合は、地点座標を中心としたズーム19のiD編集画面を開きます。サイトからOSMへデータを自動書き込みする処理はありません。

### YOKOZE Atlasへ確認情報を提供する

投稿者が現地調査や施設への問い合わせで確認した名称、位置、利用条件、設備等を入力します。既存OSM地点から開いた場合も、OSM値は別枠の参考表示に留めます。下書きは `submitted` として扱い、`cc0_eligible: false` のまま管理者へ渡します。独立確認と権利確認を終えた情報だけを `verified` に変更し、CC0用GeoJSONへ追加します。

新しい地点では、YOKOZE Atlasだけに提供するか、Atlasへの提供に加えてOpenStreetMapにも追加するかを選べます。後者では、確認位置を中心としたiDエディタへのリンクを表示しますが、OSMへの追加操作と保存は利用者がOpenStreetMap上で行います。

## ローカル確認方法

リポジトリのルートで静的HTTPサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで次を開きます。

```text
http://localhost:8000/toilet-access-map/
```

`file://` ではなくHTTPサーバー経由で確認してください。

## GitHub Pages公開方法

GitHub Pagesを `main` ブランチのルートから公開する場合、公開後のURLは次の形になります。

```text
https://furuhashilab.github.io/YOKOZEatlas2026/toilet-access-map/
```

## 取り込みプレビュー

サイト内の「取り込み」パネルから、手元のGeoJSONまたはSVGを読み込んで地図上でプレビューできます。この機能は確認作業の補助です。読み込んだデータは自動で保存されず、正式GeoJSONへも自動追加されません。

投稿フォームの入力内容から、管理者確認用の下書きGeoJSONとSVGも生成・保存できます。

ユーザーが手動で読み込んだGeoJSONやSVGのライセンスは、読み込んだデータの提供条件に従ってください。

## 投稿フロー

一般利用者はGitHubアカウントなしで投稿文や下書きファイルを作成できます。これはブラウザ内でファイルや文章を生成する仕組みであり、投稿内容を自動公開する仕組みではありません。

- フォーム送信時に、スマートフォン等では共有メニューを開きます。
- 共有メニューが使えない環境では、投稿文をクリップボードへコピーします。
- メールボタンから、投稿文入りのメール作成画面を開けます。
- GitHub Issue作成ボタンは、管理者・ゼミ生などGitHubを使える人向けの補助導線です。

この試作版は静的サイトのため、投稿内容をサーバーへ直接保存しません。公開運用時は、メール、共有先、フォームURLなど、投稿受付先を別途案内してください。

## OSM候補レイヤー

既定レイヤーとして、次の既存GeoJSONを読み込みます。

```text
../data/reference/osm_toilet_candidates.geojson
```

このファイルは、既存のOSM由来候補ファイルを変更せずに `data/reference/` へ複製した参考レイヤーです。JavaScript側で表示用プロパティを補完し、候補地点の重複可能性があっても、自動削除・統合・除外は行いません。

## 背景地図

地図設定パネルから、背景地図を選択できます。

- OSM / OpenFreeMap
- 国土地理院 標準地図

国土地理院タイルは、地理院タイル一覧ページの出典表記に従い、サイト内およびMapLibreの帰属表示に国土地理院へのリンクを表示します。

## 現在の制約と今後の課題

- 確認済みCC0トイレデータは0件です。
- OSM参考地点はCC0公開データではありません。
- 一般利用者の投稿にはGitHubアカウントを要求しません。
- 投稿後も、確認済みデータとして承認されるまで地図には反映されません。
- 横瀬町または施設管理者への問い合わせ、現地調査、CC0公開可否の確認が必要です。
