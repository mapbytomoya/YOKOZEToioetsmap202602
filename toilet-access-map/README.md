# 横瀬トイレデータプロジェクト

このディレクトリは、GitHub Pagesで公開できる静的Web地図の試作版です。ビルド工程、APIキー、サーバーサイド処理は使用しません。

## このプロジェクトについて

本プロジェクトは横瀬町のトイレマップを完成させることが目的ではありません。市民参加によって地域情報を継続的に整備するための仕組みを設計し、その実証としてトイレ情報を対象にしています。

OpenStreetMapの共同編集性と、CC0による公開データ整備を組み合わせることで、閉鎖的ではない地域オープンデータ基盤を目指します。利用者を地図の閲覧者だけでなく、地域データを育てる共同編集者として位置づけます。

トイレはケーススタディです。同じデータ状態、確認フロー、ライセンス分離の考え方を、AED、避難所、ベンチ、給水所、ロードヒーティング、バリアフリー設備などへ展開できる共通基盤を目指します。

## 現在の状態

- 本サイトは完成済みの網羅的地図ではありません。
- 初期表示では、既存のOSM由来トイレ候補GeoJSONに含まれる全Point Featureを `reference` として表示します。
- ピンの色はWheelmap風に車いす対応状況で分けます。
  - 緑: 利用しやすい
  - 黄: 一部利用可・要確認
  - 赤: 車いす対応なし
  - 灰: 未確認
- 地図設定パネルから車いす対応状況で絞り込めます。
- OSM候補地点はOpenStreetMap由来で、ODbL 1.0の参考情報です。
- 正確なトイレ入口位置、設備、利用条件、トイレ固有の利用時間は独立確認前です。
- GitHub Issueで提供された情報は、形式・座標検査後に青い確認待ちピンとして自動反映されます。
- 確認待ちピンはCC0未収録で、確認済みデータへの昇格は自動化しません。
- 既存ファイルの命名規則は維持し、既存GeoJSON/FGBは変更していません。
- ルートCC0と第三者データのライセンス範囲は異なります。
- 一般利用者向け画面では、ログイン不要の入力方法と4段階の情報提供フローを案内しています。

## 情報提供の考え方

- OSM参考地点のポップアップには「OpenStreetMapで編集する」と「確認した情報を提供する」の二つの経路を表示します。
- 新しいトイレや不足情報は、OSMアカウントなしでOpenStreetMapへメモを残せます。メモを見たマッパーが確認・編集し、編集結果はODbLで共有されます。
- YOKOZE Atlasへの情報提供用下書きはブラウザ内で作るため、作成段階ではログインを要求しません。
- YOKOZE Atlasのフォームには、OSM参考情報を読み取り専用で表示します。OSMの名称・種別・座標・設備タグを提供者の確認情報へ自動転記しません。
- 情報提供用の下書きはGeoJSON、SVG、テキストとして保存・コピーできます。
- GitHub Issueを使った場合、Actionsが受付内容を `submitted` GeoJSONへ自動変換します。GitHub Issueを開くにはGitHubアカウントが必要です。
- 受付先はメール、共有先、Webフォーム、GitHub Issueなどへ後から置き換えられます。
- 確認済みデータは標準的なGeoJSONとして管理し、CC0対象データとOSM参考データを混在させません。

## 更新経路と操作方法

画面右下の「トイレ情報を更新する」から、まず「新しいトイレ」または「既存のトイレ」を選び、次に以下の三つの更新方法を選択します。

1. OpenStreetMapで直接編集する（OSMアカウントが必要）
2. OpenStreetMapへメモを残す（アカウント不要）
3. GitHub Issueで確認情報を送り、Actionsで確認待ち地図へ自動反映する

新規地点では次に地図上の場所をクリックします。既存地点では次に地図上の既存ピンを選択します。

### OpenStreetMapへ匿名メモを残す

新しい地点では、選択位置を中心としたOpenStreetMap Notes作成画面を開きます。新規メモにはOSMアカウントが不要で、メモを見たマッパーが現地状況を確認し、必要に応じてOSMを編集します。既存のOSM候補地点では、引き続きiDエディタで対象オブジェクトを開けます。サイトからOSMへデータを自動書き込みする処理はありません。

### YOKOZE Atlasへ確認情報を提供する

提供者が現地調査や施設への問い合わせで確認した名称、位置、利用条件、営業時間、外観、水洗方式、和式・洋式、設備等を入力します。新しい地点には青い仮ピンを置けます。既存OSM地点から開いた場合も、OSM値は別枠の参考表示に留めます。

GitHub Issueで送った内容はActionsが検査し、`data/submitted/submitted_toilets.geojson` へ `cc0_eligible: false` の確認待ちデータとして自動反映します。Issueを閉じるとレイヤーから外れます。独立確認と権利確認を終えた情報だけを `verified` に変更し、CC0用GeoJSONへ追加します。

新しい地点では、YOKOZE Atlasだけに提供するか、Atlasへの提供に加えてOpenStreetMapへ匿名メモを残すかを選べます。後者でもOSMデータは自動編集せず、マッパーによる確認を経由します。

## ローカル確認方法

リポジトリのルートで静的HTTPサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで次を開きます。

```text
http://localhost:8000/toilet-access-map/
```

`file://` ではなくHTTPサーバー経由で確認してください。

## GitHub Pages公開方法

GitHub Pagesを `main` ブランチのルートから公開する場合、公開後のURLは次の形になります。

```text
https://mapbytomoya.github.io/YOKOZEToioetsmap202602/toilet-access-map/
```

## 取り込みプレビュー

サイト内の「取り込み」パネルから、手元のGeoJSONまたはSVGを読み込んで地図上でプレビューできます。この機能は確認作業の補助です。読み込んだデータは自動で保存されず、正式GeoJSONへも自動追加されません。

情報提供フォームの入力内容から、管理者確認用の下書きGeoJSONとSVGも生成・保存できます。

ユーザーが手動で読み込んだGeoJSONやSVGのライセンスは、読み込んだデータの提供条件に従ってください。

## 情報提供フロー

一般利用者はGitHubアカウントなしで情報提供文や下書きファイルを作成でき、OpenStreetMapへ新規メモを残せます。GitHub Issue経路だけはGitHubアカウントが必要です。

- フォーム送信時に、スマートフォン等では共有メニューを開きます。
- 共有メニューが使えない環境では、情報提供文をクリップボードへコピーします。
- メールボタンから、情報提供文入りのメール作成画面を開けます。
- GitHub Issue作成後はActionsが検査し、青い確認待ちピンを自動生成します。

この試作版は静的サイトのため、ブラウザからリポジトリへ直接書き込みません。GitHub Issueが受付口、GitHub Actionsが自動変換処理を担当します。

## OSM候補レイヤー

既定レイヤーとして、次の既存GeoJSONを読み込みます。

```text
../data/reference/osm_toilet_candidates.geojson
```

このファイルは、既存のOSM由来候補ファイルを変更せずに `data/reference/` へ複製した参考レイヤーです。JavaScript側で表示用プロパティを補完し、候補地点の重複可能性があっても、自動削除・統合・除外は行いません。

## 背景地図

地図設定パネルから、背景地図を選択できます。

- OSM / OpenFreeMap
- 国土地理院 標準地図

国土地理院タイルは、地理院タイル一覧ページの出典表記に従い、サイト内およびMapLibreの帰属表示に国土地理院へのリンクを表示します。

## 現在の制約と今後の課題

- 確認済みCC0トイレデータは0件です。
- OSM参考地点はCC0公開データではありません。
- 一般利用者の情報提供にはGitHubアカウントを要求しません。
- Issue受付後は確認待ちレイヤーへ自動反映されますが、確認済みCC0データには自動昇格しません。
- 横瀬町または施設管理者への問い合わせ、現地調査、CC0公開可否の確認が必要です。
