地域データを、地域のみんなで育てる

市民参加型オープンデータ基盤

みんなで横瀬町のトイレ情報を育てる、市民参加型オープンデータプロジェクトです。

このサイトは、完成した地図を提供するサービスではありません。市民・観光客・地域関係者・学生が継続的に確認・更新し、地域情報をオープンデータとして育てていくための試作です。

現在表示している地点の多くはOpenStreetMap由来の参考情報です。現地確認や施設への問い合わせで確認された情報だけを、管理者確認後にCC0で公開していきます。

  • 誰でも情報提供できます
  • 誰でもOpenStreetMapを更新できます（OSMアカウントが必要です）
  • 確認済みデータは管理者確認後に公開されます

このサイトについて

共同編集とCC0整備を両立する

OpenStreetMapの共同編集性と、独自確認した情報をCC0で公開する流れを分けています。二つのデータは自動的に混ぜません。

OpenStreetMap ↓ 共同編集 ↓ ODbL
YOKOZE Atlas ↓ 現地確認 ↓ 管理者確認 ↓ CC0公開
データと更新方法を詳しく見る

OSM参考地点はODbL 1.0、YOKOZE Atlas確認済みデータはCC0 1.0として分けて扱います。OSMを更新してもAtlasのCC0データへ自動移行せず、Atlasへの提供内容も自動公開されません。

OSMでは現地で確認できた内容だけを更新し、他の地図サービスから情報をコピーしないでください。存在や重複が不明な地点を推測で削除・統合しないでください。

車いす対応の見方

利用しやすい 一部利用可・要確認 車いす対応なし 未確認

参考地点、確認待ち、確認済みデータはポップアップ内のデータ状態で確認できます。

確認情報が公開データになるまで

  1. 地図でトイレの場所を選ぶ
  2. 確認した情報を入力する
  3. コピー、メール、共有、GitHubで送る
  4. 内容確認後に地図へ反映される
管理者による確認内容
  • 重複、座標、情報源、ライセンスを確認
  • 必要に応じて電話・メール確認や現地再調査
  • 採用情報をCC0用GeoJSONへ追加
  • GitHub Pagesを更新

新しいトイレ情報を提供する

このフォームは、OpenStreetMapの情報をコピーするためのものではありません。現地で確認した内容、施設管理者へ問い合わせた内容、または提供を受けた情報を入力してください。

入力内容はすぐには地図へ公開されません。管理者・ゼミ生が位置、重複、情報源、利用条件、ライセンスを確認した後、採用された情報だけがCC0データへ追加されます。

下書きはコピー、共有、メールで管理者へ送れます。GitHub Issueを利用する場合のみGitHubへのログインが必要です。

個人情報、顔写真、車両ナンバー、私有地内部の情報は提供しないでください。
