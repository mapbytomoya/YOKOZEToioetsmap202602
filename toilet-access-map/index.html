横瀬町トイレアクセスマップ

この地図について

横瀬町には、再利用可能な公衆トイレデータが十分に整備されていません。本サイトは完成済みの網羅的地図ではなく、市民参加型で情報を投稿・確認・更新するための試作版です。

投稿内容はすぐに正式データになりません。確認済み情報だけをCC0データへ追加します。利用時は現地の案内や施設管理者の指示を優先してください。営業時間や利用条件は変更される可能性があります。

投稿後の確認フロー

  1. 利用者が投稿
  2. GitHub Issueとして登録
  3. 管理者・ゼミ生が内容を確認
  4. 重複、位置、利用条件、情報源、ライセンスを確認
  5. 必要に応じて電話・メール・現地調査
  6. 承認された情報だけをCC0用GeoJSONへ追加
  7. Web地図へ反映

GitHub Issueへ投稿

トイレ情報を投稿する

投稿にはGitHubアカウントが必要です。Issueを作成しただけでは地図へ反映されません。

個人情報、顔写真、車両ナンバー、私有地内部の情報は投稿しないでください。
