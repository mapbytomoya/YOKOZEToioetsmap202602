地域データを、地域のみんなで育てる

市民参加型オープンデータ基盤

みんなで横瀬町のトイレ情報を育てる、市民参加型オープンデータプロジェクトです。

このサイトは、完成した地図を提供するサービスではありません。市民・観光客・地域関係者・学生が継続的に確認・更新し、地域情報をオープンデータとして育てていくための試作です。

現在表示している地点の多くはOpenStreetMap由来の参考情報です。現地確認や施設への問い合わせで確認された情報だけを、管理者確認後にCC0で公開していきます。

  • 誰でも情報提供できます
  • 新しいトイレはOSMへアカウントなしでメモを残せます
  • GitHub Issueの確認待ちデータはActionsが自動反映します
  • 確認済みCC0データへの昇格だけは権利確認後に行います

このサイトについて

共同編集とCC0整備を両立する

OpenStreetMapの共同編集性と、独自確認した情報をCC0で公開する流れを分けています。二つのデータは自動的に混ぜません。

OpenStreetMap ↓ 匿名メモ ↓ マッパーが確認・編集 ↓ ODbL
YOKOZE Atlas ↓ GitHub Issue ↓ Actions自動検査・確認待ち公開 ↓ 権利・内容確認 ↓ CC0公開
データと更新方法を詳しく見る

OSM参考地点はODbL 1.0、Issueから自動生成した確認待ち地点はCC0未収録、YOKOZE Atlas確認済みデータはCC0 1.0として分けて扱います。

新規OSMメモはログインなしで残せます。メモだけを根拠に機械的な編集は行わず、地域のマッパーが内容と現地状況を確認してOSMを更新します。

車いす対応の見方

利用しやすい 一部利用可・要確認 車いす対応なし 未確認

参考地点、確認待ち、確認済みデータはポップアップ内のデータ状態で確認できます。

確認情報が公開データになるまで

  1. 地図でトイレの場所を選ぶ
  2. 確認した情報を入力する
  3. GitHub Issueで送る、またはOSMへ匿名メモを残す
  4. IssueはActionsが青い確認待ちピンへ自動反映する
  5. OSMメモはマッパーが確認して地図を更新する
  6. 権利確認済み情報だけCC0データへ昇格する
管理者による確認内容
  • 重複、座標、情報源、ライセンスを確認
  • 必要に応じて電話・メール確認や現地再調査
  • 採用情報をCC0用GeoJSONへ追加
  • GitHub Pagesを更新

新しいトイレ地点を登録する

このフォームは、OpenStreetMapの情報をコピーするためのものではありません。現地で確認した内容、施設管理者へ問い合わせた内容、または提供を受けた情報を入力してください。

GitHub Issueで送った内容は、Actionsが形式と座標を検査し、青い「確認待ち」ピンとして自動反映します。この段階ではCC0確認済みデータではありません。

下書きはコピー、共有、メールでも保存できます。GitHub Issueを利用する場合のみGitHubへのログインが必要です。新しいトイレのOSMメモはログインなしで残せます。

個人情報、顔写真、車両ナンバー、私有地内部の情報は提供しないでください。
